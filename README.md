# dotfiles

My dotfiles for my Arch Linux installation. Backed up using `stow`.

- **Shell:** bash
- **WM:** i3
- **Text Editor:** vim
- **App launcher:** rofi / dmenu
- **Bar:** polybar
- **Bar Fonts:** Iosevka / Hack / Font Awesome
- **Terminal Font:** Source Code Pro
